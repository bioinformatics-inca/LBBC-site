# LBBC — Site do Laboratório

Site do **Laboratório de Bioinformática e Biologia Computacional (LBBC)** do Instituto Nacional do Câncer (INCA), hospedado via GitHub Pages.

🔗 **Site:** https://bioinformatics-inca.github.io/LBBC-site/

---

## Estrutura

```
lbbcc-site/
├── index.html   # Página principal (arquivo único, self-contained)
└── README.md
```

## Como atualizar o site

1. Edite o `index.html` diretamente no GitHub (botão ✏️) ou localmente
2. Faça commit na branch `main`
3. O site atualiza automaticamente em ~1 minuto

## Como publicar pela primeira vez

1. Crie um repositório no GitHub chamado `lbbcc-site`
2. Faça upload dos arquivos (ou siga o guia abaixo)
3. Vá em **Settings → Pages → Source → Deploy from branch → main → / (root)**
4. Aguarde ~1 minuto e acesse o link gerado

## Deploy via terminal (opcional)

```bash
git clone https://github.com/[seu-usuario]/lbbcc-site.git
cd lbbcc-site
# edite o index.html
git add .
git commit -m "atualiza site"
git push
```
